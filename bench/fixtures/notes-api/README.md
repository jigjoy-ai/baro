# notes-api

A tiny notes HTTP API.

## Running

```sh
npm start   # starts the server on http://localhost:3000
npm test    # runs the node:test suite
```

## API

A note has the shape `{ "id": "1", "text": "..." }`. Ids are generated by the server as strings and are never reused.

Errors from the routes below respond with a JSON body of the form `{ "error": "..." }`. Any other method or path responds with `404` and an empty body.

Notes are kept in memory only and are lost when the server restarts.

### GET /notes

Lists all notes in creation order.

- Request body: none
- Responses:
  - `200` — JSON array of notes

```sh
curl http://localhost:3000/notes
```

### POST /notes

Creates a note.

- Request body: `{ "text": string }` — `text` is required and must be a non-empty string
- Responses:
  - `201` — the created note, e.g. `{ "id": "1", "text": "hello" }`
  - `400` — the body is not valid JSON, or `text` is missing, not a string, or empty

```sh
curl -X POST http://localhost:3000/notes \
  -H "content-type: application/json" \
  -d '{"text":"hello"}'
```

### DELETE /notes/:id

Deletes the note with the given id.

- Request body: none
- Responses:
  - `204` — the note was deleted (empty body)
  - `404` — no note with that id exists

```sh
curl -X DELETE http://localhost:3000/notes/1
```
