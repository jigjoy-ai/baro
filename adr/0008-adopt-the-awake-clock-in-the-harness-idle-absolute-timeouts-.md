# ADR-0008: Adopt the awake clock in the harness idle/absolute timeouts and suppress gap-driven false 'hung process' verdicts

**Status:** Accepted
**Context:** exec-file-cli.ts already isolates all timers behind `ExecFileCliTimers` with two hand-rolled fakes that must keep compiling; liveness.ts and process-cpu-activity.ts decide whether to kill a child. A suspend must not shorten these windows (a sleeping machine is not a hung child) and must not silently lengthen them either — the constraint forbids both.
**Decision:** src/harness/exec-file-cli.ts: leave `ExecFileCliTimers` and `REAL_TIMERS` (:34-42) untouched; add `awakeClock?: AwakeClock` to `ExecFileCliOptions` next to `timers?` (:72-73) and resolve it as `const clock = options.awakeClock ?? sharedAwakeClock()` beside `const timers = options.timers ?? REAL_TIMERS` (:155). The absolute timeout (:199) and the idle re-arm (:265) keep arming through `timers`, but the callback must re-check before acting: compute expiry against `clock.awakeNow()` and, when awake remaining is still positive, re-arm the same window with the remaining awake time instead of declaring a timeout. The CPU-probe race bound (:236) and all cleanup (:165-167,:248,:263) keep using `timers`. Both existing fakes therefore keep working unchanged, and the arm-count assertions in test/harness/exec-file-cli.test.ts:189-199 must still hold for the no-gap case.

src/harness/liveness.ts: same treatment for its idle and absolute windows, budget name `"harness-liveness"`.

src/harness/process-cpu-activity.ts: the hung-process window must reset rather than accuse across a gap. Before judging a sample window, call `clock.sample()`; if a gap was absorbed since the window baseline, discard the window, re-baseline from `clock.awakeNow()` and report no CPU-idle evidence for that window. Never shorten a window because of a gap.
**Consequences:** Because the harness keeps arming through `timers` and only re-checks through `clock`, the two existing per-file timer fakes stay valid and ADR-untouched. A suspend during a child run neither kills the child nor grants it extra awake idle time — that pair is exactly the regression test the acceptance criteria demand.
