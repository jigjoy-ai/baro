# ADR-0003: Add one node:test file at test/operator/operator-session.test.ts

**Status:** Accepted
**Context:** This follows the house style of `test/operator/run-registry.test.ts`. The glob in package.json:15 requires the `*.test.ts` suffix.
**Decision:** Create `packages/baro-orchestrator/test/operator/operator-session.test.ts` with these imports: `import assert from "node:assert/strict";`, `import { describe, it } from "node:test";` and `import { systemPrompt } from "../../src/operator/operator-session.js";`. Add one `describe("systemPrompt")` block with one `it` that calls `const prompt = systemPrompt("/tmp/project")`. Use `assert.ok(prompt.includes(...))` to check each of these substrings: "mirror the language of the person's most recent message", "answers, questions, progress notes, and the final report", "switch with them", "Keep English for code-facing artefacts", "commit messages", "goal text passed to `delegate`", "file contents", "identifiers". Do not define a shared rule-text constant, and do not add helpers or fixtures.
**Consequences:** Run it with `npm test` in packages/baro-orchestrator. Editing the rule wording means updating these substrings too. No other files change, including docs and the README.
