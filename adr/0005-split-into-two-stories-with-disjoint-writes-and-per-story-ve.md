# ADR-0005: Split into two stories with disjoint writes and per-story verification perimeters

**Status:** Accepted
**Context:** The goal requires each story to declare non-overlapping writes and to verify only its own perimeter. The transport fix and the diff cap touch disjoint files once the cap lives in its own module (ADR 3).
**Decision:** Story 1 — 'stdout flush on exit'. writes: ["packages/baro-orchestrator/src/tui-protocol.ts", "packages/baro-orchestrator/scripts/cli.ts", "packages/baro-orchestrator/test/tui-protocol.test.ts"]. Implements ADR-001, ADR-002 and test group A. Verification: `node --import tsx --test packages/baro-orchestrator/test/tui-protocol.test.ts` plus `npm run typecheck -w @baro/orchestrator`.

Story 2 — 'run diff byte cap'. writes: ["packages/baro-orchestrator/src/integration/run-diff-cap.ts", "packages/baro-orchestrator/src/orchestrate.ts", "packages/baro-orchestrator/test/orchestrate-run-diff-cap.test.ts"]. Implements ADR-003 and test group B. Verification: `node --import tsx --test packages/baro-orchestrator/test/orchestrate-run-diff-cap.test.ts` plus `npm run typecheck -w @baro/orchestrator`.

Neither story may write any path under crates/, nor src/integration/git.ts, src/integration/git-coordinator.ts, src/main.ts, or any other test file. Neither story runs the package-wide `npm test`, the lane scripts, cargo, or any repo-wide gate; a single isolated rerun of a targeted command is permitted on load-related flake. The stories are independent and may run in parallel.
**Consequences:** No file is written by both stories, so parallel execution needs no merge coordination. The shared surface between them is only the ADR text — Story 2 does not import anything Story 1 adds. Both stories must add their constant values (TUI_FLUSH_TIMEOUT_MS, MAX_RUN_DIFF_BYTES) and the chosen flush location to the PR description, including the noted cli.ts integration-coverage gap.
