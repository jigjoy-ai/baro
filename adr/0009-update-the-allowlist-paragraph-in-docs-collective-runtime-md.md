# ADR-0009: Update the allowlist paragraph in docs/collective-runtime.md only

**Status:** Accepted
**Context:** Scouting found exactly one doc that enumerates the allowlist: the unheaded paragraph at docs/collective-runtime.md:192-209 under '## Distributed autonomy and runtime graph changes'. No README, AGENTS.md, CLAUDE.md or other docs/*.md file lists the routes. The paragraph's route clause also predates the npx rstest route.
**Decision:** Edit only the route-list sentence at docs/collective-runtime.md:196-199, extending the semicolon-delimited clause to read (after '...and exact `git diff --check`'): '; conventional Composer `build`, `typecheck`, `test`, `lint`, or `check` scripts anchored to a root `composer.json`; a contained `vendor/bin/phpunit` limited to `--testsuite <name>`, `-c`/`--configuration <file>`, and contained test paths; and `ddev exec <command>` as a transparent prefix that requires `.ddev/config.yaml` and re-applies the same policy to the wrapped command.' Also add 'exact `npx rstest run` paths' to the same clause so the doc matches the code. Add one sentence to the same paragraph: 'Composer trust is a separate baseline set from the npm one, and `ddev exec` grants no authority: a wrapped command the translator would reject directly stays rejected with the same reason.' Do NOT add a new heading, do NOT create a new doc file, do NOT touch README.md, CHANGELOG.md, AGENTS.md or CLAUDE.md, and do NOT edit the runbook code block at :323 or the '## Provider-free verification' section.
**Consequences:** Documentation stays in one place with the existing prose voice. The pre-existing npx omission is corrected in the same edit rather than left as a second discrepancy.
