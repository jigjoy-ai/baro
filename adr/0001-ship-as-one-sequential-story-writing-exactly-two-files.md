# ADR-0001: Ship as one sequential story writing exactly two files

**Status:** Accepted
**Context:** The envelope allows a two-story split only if the 'writes' arrays are disjoint. Both gaps (translatePackage workspace support, translatePhpunit relative args) modify packages/baro-orchestrator/src/verification/declared-verification.ts and both need new cases in the single test file, so no disjoint split exists. Splitting would force two agents to edit the same two files.
**Decision:** Plan exactly ONE story. Its writes array is exactly ["packages/baro-orchestrator/src/verification/declared-verification.ts", "packages/baro-orchestrator/test/verification/declared-verification.test.ts"]. Create no new source, helper, or fixture files. Do not modify verify.ts, prd-declared-tests.ts, continuous-gate-runner.ts, package.json, or any other file. Verification perimeter for the story, run from packages/baro-orchestrator: `node --import tsx --test "test/verification/declared-verification.test.ts"` and `npx tsc -p tsconfig.json --noEmit`. Do NOT run `npm test` or any repository-wide suite; do not reinstall dependencies. If the targeted test fails under load, rerun that single file once in isolation; the isolated pass is authoritative.
**Consequences:** No coordination problem between agents. Both gaps land in one diff; the PR description must contain the explicit containedPaths note required by ADR-006.
