# ADR-0007: Prove the resume routing at the factory and board seams only, without re-testing worktree behavior

**Status:** Accepted
**Context:** S1 already proves base-SHA movement, replay and rollback against a real git repo in test/integration/worktree-suspension-lineage.test.ts. The factory seam is the injected `worktrees` option (story-factory.ts:129), doubled as an object-literal cast in test/market/story-factory.test.ts:427-434; the board seam is event-level only.
**Decision:** Add packages/baro-orchestrator/test/market/story-factory-resume.test.ts, modeled on test/market/story-factory.test.ts:422-461: double is `{ create: async (id) => {...}, resumeFromSuspension: async (id, opts) => {...}, activePath: () => "/tmp/wt/S1" } as unknown as WorktreeManager` recording calls in plain arrays. Required cases: (1) spawn with `resume: { preservedBranch: "baro-recovery/run/S1/1" }` calls `resumeFromSuspension` exactly once with `("S1", { restoreFrom: "baro-recovery/run/S1/1" })`, never calls `create`, and the CapturingExecutor receives `cwd === "/tmp/wt/S1"`; (2) spawn with `resume: { preservedBranch: null }` calls `resumeFromSuspension("S1", {})`; (3) spawn without `resume` calls `create` only; (4) `resumeFromSuspension` rejecting with `requireWorktree: true` produces the existing `isolated worktree unavailable` failure and never calls `create`.
Add packages/baro-orchestrator/test/execution/collective-board-resume-directive.test.ts, modeled on test/execution/collective-board-dependency-block.test.ts:38-192: drive the dependency-suspension sequence and assert the re-offer `WorkOffered` carries `request.resume.preservedBranch === "baro-recovery/run/S1/1"` (and that a first, non-resumed offer has `request.resume === undefined`). The board test asserts event payloads only — it must not construct a WorktreeManager.
Do NOT assert git state, base SHAs, or replay outcomes in either file; that is S1's coverage.
**Consequences:** Story B's targeted verification is `cd packages/baro-orchestrator && node --import tsx --test test/market/story-factory-resume.test.ts test/market/story-factory.test.ts test/execution/collective-board-resume-directive.test.ts test/execution/collective-board-dependency-block.test.ts` plus a typecheck of the package. No repository-wide suite. On a load-induced failure, rerun the single failing file once in isolation; an isolated pass decides.
