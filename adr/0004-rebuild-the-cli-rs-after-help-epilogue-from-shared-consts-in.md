# ADR-0004: Rebuild the cli.rs `after_help` epilogue from shared consts in usage.rs

**Status:** Accepted
**Context:** The epilogue at cli/cli.rs:12 is an inline literal listing only `baro watch <run-id>` and `baro logs <run-id> [--follow]`, plus the `--resume`/`--continue` note and the Issues/Twitter links. The goal requires the epilogue and per-command usage to share a text source. Existing tests render `Cli::command().render_long_help()` and assert on substrings (cli/cli.rs:417-428), so the epilogue's rendered content must stay stable for those assertions.
**Decision:** In `src/cli/usage.rs` define one shared summary line per command as a private const, e.g. `const WATCH_SUMMARY: &str = "  baro watch <run-id>            follow a live run and print milestone events";` and likewise `CONNECT_SUMMARY`, `LOGIN_SUMMARY`, `RUNS_SUMMARY`, `STOP_SUMMARY`, `LOGS_SUMMARY` (logs keeps `[--follow]`). Build `pub const AFTER_HELP: &str = concat!("Run commands (handled before flag parsing):\n", CONNECT_SUMMARY, "\n", LOGIN_SUMMARY, "\n", RUNS_SUMMARY, "\n", STOP_SUMMARY, "\n", WATCH_SUMMARY, "\n", LOGS_SUMMARY, "\n\n--resume never re-plans; --continue always re-plans.\n\nIssues: https://github.com/jigjoy-ai/baro/issues\nTwitter: @lotus_sbc");` — the trailing three paragraphs are copied verbatim from the current literal. Each per-command usage const is likewise built with `concat!` from its own summary line, so wording is shared, e.g. `pub const LOGS_USAGE: &str = concat!("Usage: baro logs <run-id> [--follow]\n\n", <purpose sentence>, "\n\nFlags:\n  --follow    tail the log instead of printing it once\n  -h, --help  print this help\n  --version   print the version\n\nExample:\n  baro logs r-1a2b --follow\n");`. In `crates/baro-tui/src/cli/cli.rs` replace the inline literal on line 12 with `after_help = crate::cli::usage::AFTER_HELP`; change nothing else in that `#[command(...)]` attribute. Every usage const must include a Usage line, a one-line purpose, a Flags block, and exactly one `Example:` block.
**Consequences:** The epilogue grows from two commands to six; the existing render_long_help assertions at cli/cli.rs:420-428 target `--shell-budget` and `--resume`/`--continue` wording and remain valid. Add one assertion that `render_long_help()` contains `usage::WATCH_SUMMARY`-equivalent text so drift between the two surfaces fails the build.
