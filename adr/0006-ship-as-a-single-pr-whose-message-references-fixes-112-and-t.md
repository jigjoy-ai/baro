# ADR-0006: Ship as a single PR whose message references Fixes #112 and touches no verification module

**Status:** Accepted
**Context:** The goal requires the PR to close issue #112 on merge and states the terminal fail-closed gate must be untouched; the repository records decisions under adr/ with numbered slug filenames.
**Decision:** The commit message and PR body MUST contain the literal line `Fixes #112`. The change set is limited to: packages/baro-orchestrator/src/planning/domain/planner-prompts.ts, packages/baro-orchestrator/src/planning/adapters/planner-bus-session.ts, optionally packages/baro-orchestrator/src/planning/adapters/planner-harness-progressive.ts and planner-openai-progressive.ts (only if a test proves a gap), and the one new test file. Do NOT edit anything under packages/baro-orchestrator/src/verification/, packages/baro-orchestrator/src/goal/goal-contract.ts, or packages/baro-orchestrator/src/execution/collective-board.ts. Comments follow the repo convention in CLAUDE.md: no banner dividers, no narration; at most a one-line 'why' where a constraint is non-obvious.
**Consequences:** Reviewers can verify the fail-closed non-goal by the diff's file list alone. Any need to touch a verification file means the design was misread and must come back for a new ADR.
