# ADR-0016: Order the stories that edit the same files

**Status:** Accepted
**Context:** Stories run in parallel worktrees, and several items touch the same files.
**Decision:** Dependencies (dependsOn):
- #141 after #159, #140 and #144-prompt.
- #162 after #148.
- #163 after #162.

#144 is split into two stories:
- #144a covers the lane guard and the event.
- #144b covers admission and the operator prompt, and depends on #144a.

Everything else is independent:
- #136 and #161.
- #119, #152 and #149, which are Rust-only.
- #140 (Rust run_state) and #152 share only main.rs, in different regions; #152 depends on #140 to avoid main.rs conflicts.

No story runs git push, calls gh, or calls the GitHub API.
**Consequences:** Each story's writes must list the exact files named in its decision, so the write-surface gate stays meaningful.
