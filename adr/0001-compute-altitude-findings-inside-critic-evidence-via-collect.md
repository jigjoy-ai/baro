# ADR-0001: Compute altitude findings inside critic-evidence via collectAltitudeFindings only

**Status:** Accepted
**Context:** Findings must be derived without re-implementing or modifying altitude.ts, altitude-probe.ts or the gate registration. critic-evidence.ts already has exactly the three inputs AltitudeProbeOptions needs. Calling the low-level pure helpers (parseNumstat/altitudeFindings/countLines) directly would duplicate probe() and its bounded git/file I/O; rejected.
**Decision:** In packages/baro-orchestrator/src/acceptance/critic-evidence.ts add imports `import { collectAltitudeFindings } from "./altitude-probe.js";` and `import { altitudeActivityText, renderAltitudeEvidenceSection, type AltitudeFinding } from "./altitude.js";`. Add ONE new module-private async function:

`async function altitudeEvidenceFor(agentId: string, source: CriticEvidenceSource | undefined): Promise<{ section: string | null; activity: string | null }>`

It MUST: (a) obtain the repository target by calling the same helper `repositoryEvidenceFor` already uses (`validatedRepositoryTarget`, critic-evidence.ts:629-665) with the same arguments — do NOT duplicate or re-implement target resolution, and do NOT call source.resolveRepositoryTarget directly; (b) return `{ section: null, activity: null }` when the target is null or its baseSha is null/empty; (c) otherwise call `collectAltitudeFindings({ cwd: <target cwd>, baseSha: <target baseSha>, timeoutMs: <the exact same timeout expression repositoryEvidenceFor passes to git, i.e. source?.gitTimeoutMs ?? the existing default constant> })`; (d) return `{ section: renderAltitudeEvidenceSection(findings), activity: altitudeActivityText(findings) }`; (e) wrap the whole body in try/catch returning `{ section: null, activity: null }` on any throw. Do NOT edit src/acceptance/altitude.ts, src/acceptance/altitude-probe.ts, src/execution/gate-registry.ts, or src/acceptance/critic-verdict.ts. Do NOT hand-format finding lines anywhere — the two altitude.ts formatters are the single owners of both string formats.
**Consequences:** Altitude I/O stays bounded (25 files / 4 MiB / 512 KiB stdout) and fails closed, so a probe failure can never fail a critic evaluation. Repos without a base sha (non-worktree/one-shot targets) simply get no advisory section, which is the specified 'no findings' behavior.
