# ADR-0002: Match drifted predicates to canon by index first, then by unique invariantId; never by field subset

**Status:** Accepted
**Context:** The goal requires an explicit matching rule. Field-subset matching is unusable here: the fields are exactly what drifted, so subset matching would be least reliable in the case it exists to serve. Pure index matching is unsafe alone because null holes are compacted and a dropped entry shifts every later index. `invariantId` alone is not a key — uniqueness is not enforced by `parsePredicate` and two predicates may claim `G-C1`. Index plus id agreement is unambiguous; unique id alone is unambiguous by definition.
**Decision:** Implement matching in `goal-constraint-appendix.ts` as a private `matchCanonicalPredicates(raw: readonly unknown[], canonical)` returning `{ matched: Map<number, number> /* raw index -> canon index */, unmatchedRaw: number[], unclaimedCanon: number[] }`. Operate on the RAW array including holes, before any hole skipping or key normalization. `identityOf(entry)` = `typeof entry === "object" && entry !== null && !Array.isArray(entry) && typeof entry.invariantId === "string" ? entry.invariantId.trim() : null`.

Pass 1 (index): for `i` in `0 .. min(raw.length, canonical.length) - 1`, if `identityOf(raw[i]) === canonical[i].invariantId` and canon index `i` is unclaimed, claim it.
Pass 2 (unique id): for each still-unmatched raw index `i` in ascending order with `identityOf(raw[i]) !== null`, collect the still-unclaimed canonical indices whose `invariantId` equals that identity; claim it only if there is EXACTLY ONE. Zero or more than one leaves the entry unmatched.
No third pass. Non-object entries, holes, and entries whose `invariantId` is missing or not a string are never matched. Key-case drift (`invariantID`, `path-suffix`) is NOT repaired before matching — an entry whose `invariantId` key itself drifted is simply unmatched.
**Consequences:** Restoration is deterministic and order-independent of the raw array's shape. A predicate whose `invariantId` drifted AND whose position moved is unmatched and therefore rejected — deliberately fail-closed. Record this rule and its rejected alternatives in the ADR from ADR-007.
