# ADR-0010: Split the work into two stories with disjoint writes and per-story targeted verification

**Status:** Accepted
**Context:** The run must declare exact non-overlapping writes per story. Source and its tests are one indivisible behavioural change (the test file asserts exact strings the source defines); the doc edit is independent prose.
**Decision:** Story A writes exactly ['packages/baro-orchestrator/src/verification/declared-verification.ts', 'packages/baro-orchestrator/test/verification/declared-verification.test.ts']. Story B writes exactly ['docs/collective-runtime.md']. No other file may be written by either story. Story A verifies with a targeted run of its own test file only (node --test over packages/baro-orchestrator/test/verification/declared-verification.test.ts via the package's existing node:test invocation, no dependency reinstall, no repository-wide test command); one isolated rerun is permitted if that targeted test fails under load and the rerun decides. Story B declares `git diff --check` as its verification. Neither story may edit verify.ts or add dependencies.
**Consequences:** Parallel execution is safe: no write overlaps and no shared build artefact. Story B carries no code risk. If Story A must adjust a doc-visible string, it changes the source string only and Story B quotes ADR-008's text, which is fixed independently of either story's ordering.
