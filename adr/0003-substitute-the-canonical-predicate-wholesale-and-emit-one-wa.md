# ADR-0003: Substitute the canonical predicate wholesale and emit one warn per restored entry using the existing canonicalized_field note kind

**Status:** Accepted
**Context:** Downstream consumers must see byte-identical canonical predicates, so partial field merges are wrong — a matched entry is replaced entirely. The reporting channel must reuse existing plumbing, and `contract-normalization.ts` semantics are constrained to stay untouched, so adding a new `ContractNoteKind` member is out. Of the three existing kinds, `canonicalized_field` is the one that already means "the host rewrote model-authored content to its canonical form".
**Decision:** When `canonical` is supplied and matching succeeds, build the validated result directly from the canonical entries in CANONICAL ORDER: the returned array is a deep copy of `canonical` (same five keys, same trimmed values), never a merge of raw and canon fields. For each matched raw index whose entry is not already deep-equal to its canonical match, emit exactly one note through `onNote`: `{ severity: "warn", kind: "canonicalized_field", path: "constraintPredicates[<rawIndex>]", detail: "constraintPredicates[<rawIndex>]: restored canonical predicate <invariantId> (<changedFields>)" }` where `<changedFields>` is the differing key names from `PREDICATE_KEYS` joined by `", "` in `PREDICATE_KEYS` order. Emit NO note for a matched entry that already equals canon (idempotent re-validation is silent). Do not emit `skipped_absent_entry` for holes when canon is supplied and the run has no defects — the hole is either matched (impossible, holes never match) or reported as an unclaimed canonical entry per ADR-004.

Do not edit `packages/baro-orchestrator/src/contract/contract-normalization.ts`. Do not add a note kind, a new note type, or a new error class.
**Consequences:** Three drifted predicates yield exactly three warns and zero defects, and the array handed to `goalPredicatesFromWire`/`attachGoalConstraintContract` is byte-identical to canon. Tests assert notes with the existing `recorder()` helper in `test/goal/goal-constraint-appendix.test.ts:32-35`.
