# ADR-0007: Fix each story's verification perimeter to its own targeted test files

**Status:** Accepted
**Context:** Repo-wide runs are a stated non-goal and are rejected by the shell; a single run-level gate verifies the merged tree. Test invocation shape is fixed by packages/baro-orchestrator/package.json:15-17.
**Decision:** Each story declares and runs only these commands, from `packages/baro-orchestrator`:
- Story A: `node --import tsx --test "test/runtime-graph/runtime-replan-board.test.ts"`.
- Story B: `node --import tsx --test "test/execution/collective-board-spawn-surface-announce.test.ts" "test/execution/collective-board.test.ts" "test/execution/collective-board-policy-replan-batch.test.ts"`.
- Story C: `node --import tsx --test --test-concurrency=2 "test/story-tool-containment.test.ts"`.
No story runs `npm test`, `npm run test:fast`, `npm run test:slow`, `cargo test`, or any glob broader than the files above; no story runs `npm install`. If a targeted test fails under load, one isolated rerun of that single file is allowed and the isolated result is authoritative.
Required new cases: Story A — added story overlapping an active non-removed non-passing story is rejected with code `overlapping_write_surface` and the reason from the reason-format ADR; a disjoint mutation is still accepted; overlap with a `passes: true` story is accepted; overlap with a story removed in the same mutation is accepted. Story B — replan applied between WorkLeaseGranted and StorySpawned that changes the surface key produces exactly one gate_rule_announced at spawn carrying the current graphVersion and the lease's leaseId/generation; a spawn with no intervening change produces no additional gate_rule_announced. Story C — `sed -n '/panicked/,+8p' out.log` and `sed -n '/start/,/end/p' out.log` pass the guard; `cat /etc/passwd` and `ls /Users` still return their existing rejection strings.
**Consequences:** Story B's file list overlaps no other story's writes (it only reads/runs existing suites it does not modify). Run-level integration verification of the merged tree happens once, outside the stories.
