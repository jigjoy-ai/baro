# ADR-0008: Place new tests in the existing goal, outcome, and bus-session test files

**Status:** Accepted
**Context:** Test conventions are fixed: `node:test` + `node:assert/strict`, valid factories cloned then damaged in place, a local `ContractNote[]` recorder passed as the last parameter, and a `defectsOf`/`rejection` helper that re-throws so the error can be asserted. `test/goal/goal-constraint-appendix` is in the fast lane per `scripts/test-lanes.mjs`.
**Decision:** Add tests only to these existing files, reusing their local helpers (`ABSENT`/`UNCHANGED` constants, `recorder()`, `defectsOf()` in the appendix test; `ready()`, `notes()`, `rejection()` in the outcome test):
- `packages/baro-orchestrator/test/goal/goal-constraint-appendix.test.ts`: (a) three predicates mangled as kind-changed, pathPrefix+text emptied, kind-changed on a third, canon supplied → returns an array `deepEqual` to canon, exactly three `canonicalized_field` warns, no throw; (b) an extra fourth predicate not in canon → throws with the `does not match any canonical constraint predicate` defect; (c) a dropped predicate → throws with the `is missing the canonical predicate` defect; (d) canon supplied and input already canonical → zero notes, result deep-equal to canon; (e) `canonical` omitted → behavior identical to today, including `skipped_absent_entry`; (f) one predicate with two field defects → both defects reported in one throw.
- `packages/baro-orchestrator/test/architect-outcome.test.ts`: the same three-defect mangled outcome with `canonicalConstraintPredicates` supplied parses cleanly and its `constraintPredicates` are deep-equal to canon; without canon it rejects with all three defects in one `ArchitectOutcomeContractError`.
- `packages/baro-orchestrator/test/architect-bus-session.test.ts`: the mangled outcome without canon drives exactly one repair round whose prompt text contains all three defect messages.
Add no new test file and no new test helper module. Verification command: `npm test -w packages/baro-orchestrator`.
**Consequences:** New coverage stays in the fast lane except the outcome-script tests, which are untouched. Reviewers see the canonicalization contract asserted at both the unit boundary and the repair-round boundary.
