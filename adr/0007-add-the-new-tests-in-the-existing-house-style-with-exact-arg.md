# ADR-0007: Add the new tests in the existing house style with exact-argv assertions

**Status:** Accepted
**Context:** The test file uses withTempDir + inline fixtures + positional translateDeclaredTests + array destructuring, and the third argument must use the object form [{manager:"npm"}] (the bare ["npm"] spelling in older tests does not match the declared type). The acceptance criteria demand exact argv assertions for the ddev case.
**Decision:** Add to packages/baro-orchestrator/test/verification/declared-verification.test.ts only. Use prefix "baro-verify-declared-workspace-" for the new workspace tests and the existing "baro-verify-declared-phpunit-" / "baro-verify-declared-ddev-" prefixes for the phpunit/ddev additions. Workspace fixture: root package.json {name:"root", private:true, workspaces:["packages/*"]}, then mkdirSync(join(dir,"packages","app"), {recursive:true}) with {name:"@baro/app", scripts:{typecheck:"tsc --noEmit", test:"rstest run", release:"do-it"}}; managers argument [{manager:"npm"}, {manager:"npm", cwd: join(dir,"packages","app")}]. Required cases: (1) happy path `npm run typecheck -w @baro/app` → cwd === join(dir,"packages","app"), args deep-equal ["run","typecheck"], label === "npm run typecheck -w @baro/app", incompleteReason undefined; (2) `npm run typecheck --workspace packages/app` and (3) `npm run typecheck --workspace=@baro/app` → same tool/args/cwd, labels preserving each declared spelling; (4) script present only in the workspace and absent from root still resolves; (5) focused args after a selector: `npm run test -w @baro/app -- tests/a.test.ts` → args deep-equal ["run","test","--","tests/a.test.ts"] with containedPaths unchanged in shape; (6) rejections asserting the exact ADR-004 strings for unknown name, missing workspaces field in root, two selectors, selector after '--', and an untrusted script (`release`) declared in the workspace manifest; (7) regression: an existing root-scoped `npm run test` declaration still yields cwd === undefined and the identical label/tool/args. Phpunit/ddev: assert args deep-equal ["-c","phpunit.xml"] and ["tests/Unit"] style relative values, tool === join(dir,"vendor","bin","phpunit"), containedPaths still absolute; and one ddev test asserting the FULL argv deep-equal ["exec","vendor/bin/phpunit","-c","phpunit.xml","tests/Unit"] plus an explicit assertion that no element of args contains the temp dir path. Platform-sensitive path tests use { skip: process.platform === "win32" } like the existing ones.
**Consequences:** Reviewers can see each acceptance criterion mapped to a named test. Only the phpunit/ddev arg expectations in pre-existing tests change; all other existing assertions must remain untouched.
