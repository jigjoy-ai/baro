# ADR-0008: Fix each story's verification to targeted per-file test commands only

**Status:** Accepted
**Context:** The run forbids repo-wide suite commands in this shell, forbids dependency reinstallation, and allows exactly one isolated rerun of a failing targeted command. The documented per-file form in this repo is `cd packages/baro-orchestrator && node --import tsx --test test/<path>.test.ts`.
**Decision:** Story 1 declares exactly:
`cd packages/baro-orchestrator && node --import tsx --test test/contract/contract-normalization.test.ts`

Story 2 declares exactly:
`cd packages/baro-orchestrator && node --import tsx --test test/architect-outcome.test.ts`
`cd packages/baro-orchestrator && node --import tsx --test test/planning/domain/architect-obligation-segments.test.ts`
`cd packages/baro-orchestrator && node --import tsx --test test/run-architect-outcome.test.ts`
`cd packages/baro-orchestrator && node --import tsx --test test/goal/goal-constraint-appendix.test.ts`
`cd packages/baro-orchestrator && node --import tsx --test test/architect-bus-session.test.ts`

Forbidden in both stories: `npm test`, `npm run test:fast`, `npm run test:slow`, `node --test "test/**/*.test.ts"`, `npm install`/`npm ci`, `cargo test`, and any cargo build. No `--test-concurrency` flag is added. A targeted command that fails under load may be rerun once in isolation; that isolated result is authoritative.
**Consequences:** run-architect-outcome.test.ts spawns the real CLI under tsx and is the slowest command in the set — it belongs to Story 2 because only Story 2 restores the `exact v1 schema` substring. goal-constraint-appendix.test.ts and architect-bus-session.test.ts are verified without being written, since they consume the shared module and could regress silently. No run-level verification gate is triggered by this change.
