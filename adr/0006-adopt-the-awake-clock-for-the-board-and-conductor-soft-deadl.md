# ADR-0006: Adopt the awake clock for the board and conductor soft deadlines, preserving the existing epoch-staleness guard

**Status:** Accepted
**Context:** collective-board.ts already implements the split/re-check idiom correctly (:3143-3195) but against `Date.now()`, and uses `this.startedAt` both as the elapsed origin (:1068) and as a staleness epoch token compared by identity in `onSoftDeadlineReached` (:3179). Conductor mirrors the same softDeadline shape. Naively swapping in awake time would break the epoch comparison if the two ever drift apart.
**Decision:** In `src/execution/collective-board.ts` and `src/execution/conductor.ts`: add `awakeClock?: AwakeClock` to the existing construction options and store the resolved clock as a private field. `this.startedAt` is assigned `clock.awakeNow()` (collective-board.ts:1068 and the conductor equivalent) and remains the single value used both as elapsed origin and as the staleness epoch — it must be read from one clock, so identity comparison at :3179 is unaffected. `softDeadlineReason()` (:3143-3149) and `softDeadlineRemainingMs()` (:3151-3157) use `clock.awakeNow()`. `armSoftDeadlineTimer()` (:3159-3175) keeps `NamedTimers` and the `SoftDeadlineReached.create({ runId, startedAt })` payload unchanged, but clamps with `AWAKE_SPLIT_MAX_DELAY_MS` instead of the literal `2_147_483_647` and arms through `clock.setTimeout` via `createAwakeDeadline({ budget: "board-soft-deadline" | "conductor-soft-deadline", ... })`; `onSoftDeadlineReached()` keeps its stale-epoch drop and its re-arm branch verbatim in shape. `scheduleOperationalRetry` / `operationalRetryDueAt` (:3197-3215) also move to `clock.awakeNow()` so the `dueAt <= dueAt` skip comparison stays in one time base. Do not change the `SoftDeadlineReached` event payload or any semantic event type string.
**Consequences:** Bus payloads and event wire types are untouched, so replay/audit readers keep working. Mixing wall and awake timestamps inside these classes is now a correctness bug — every timestamp on the board/conductor comes from the injected clock.
