# ADR-0011: Store a goal fingerprint in prd.json and decide bare-launch mode from it with a pure function

**Status:** Accepted
**Context:** Bare `baro` currently resumes whenever any story has passes == false (main.rs:1157-1158) regardless of whether the user means the same goal. There is no hashing utility in either stack and no crypto dependency to lean on; adding one for a non-security fingerprint is unwarranted.
**Decision:** Field: `goalFingerprint` (optional string) at PRD top level, next to `conversationSessionId`.
Rust executor.rs (S4): PrdFile gains `goal_fingerprint: Option<String>` serialized as `goalFingerprint` with `#[serde(default, skip_serializing_if = "Option::is_none")]`, following the file's existing serde naming style; PrdStory gains `merge_status: Option<String>` (`mergeStatus`) and `merge_commit_sha: Option<String>` (`mergeCommitSha`) with the same attributes, so ADR-008's writes survive Rust rewrites. Inline test: parse a PRD containing all three fields, re-serialize with write_prd, assert they are preserved.
Rust launch.rs (S3): `pub fn goal_fingerprint(goal: &str) -> String` = FNV-1a 64-bit over the normalized text (CRLF->LF, trim, collapse runs of whitespace to a single space), formatted `format!("fnv1a64:{:016x}", hash)`. No new crate dependency; do NOT add sha2/blake3/md5. TS never computes this value, only preserves it.
Rust launch.rs also: `pub enum LaunchMode { Fresh, Resume, Explicit }` and `pub fn decide_launch(explicit_resume: bool, explicit_continue: bool, positional_goal: Option<&str>, prd_fingerprint: Option<&str>, has_incomplete_stories: bool) -> LaunchDecision { mode, message: Option<String> }`: explicit flags always win (mode Explicit, no message); otherwise, with an incomplete PRD and a matching fingerprint -> Resume with message `found an interrupted run for this goal; resuming (use --continue to re-plan)`; incomplete PRD with a different or missing fingerprint -> Fresh with message `an unfinished prd.json exists for a different goal; starting fresh (use --continue to re-plan it)`; no incomplete PRD -> Fresh, no message.
Rust main.rs (S5): writes goal_fingerprint into the PrdFile at every plan-creation write site (main.rs:2542, 2659, 3954, 4021) using goal_fingerprint(<goal text used for the plan>), and replaces the ad-hoc resume trigger at main.rs:1157-1158 with decide_launch, printing `message` once.
cli.rs (S1) after_help must contain, verbatim: `--resume never re-plans; --continue always re-plans.`
Inline tests in launch.rs cover fingerprint stability/normalization and all decide_launch branches.
**Consequences:** PRDs written before this change have no fingerprint, so bare launch treats them as a different goal (fresh + warning) — explicit --resume still works. Fingerprint is a collision-tolerant non-cryptographic hash used only for equality of goal text; never use it as an identity or security token.
