# ADR-0003: Propagate the invariant gap through planner-harness-progressive.ts and planner-bus-session.ts as a mirror of the obligation path

**Status:** Accepted
**Context:** The constraint requires all three fragment-publishing adapters to carry the same coverage receipt information for both the claude lane and the native lane. The harness layer forwards publish verbatim but declares its own gap-source shim; bus-session owns the prose clause and the retry input.
**Decision:** packages/baro-orchestrator/src/planning/adapters/planner-harness-progressive.ts: extend `interface ProgressiveGapSource` (:77-80) with `unownedInvariantIds?(): readonly string[]`; mirror the existing `?.() ?? []` read at :172-173 into a sibling `unownedInvariantIds` value exposed on the same surface as the obligation one (:106-107); add the no-op `unownedInvariantIds: () => []` to the disabled object at :125. The publish forward at :166-169 and :370 stays a verbatim pass-through — do NOT strip or re-shape the new receipt keys.
packages/baro-orchestrator/src/planning/adapters/planner-bus-session.ts: add `unownedInvariantsClause(ids: readonly string[]): string` beside :111-120, using `formatInvariantIdList`, and `resolveUnownedInvariants(error: unknown): readonly string[]` beside :534-537, preferring `missingInvariantIdsFromError(error)` (ADR-006) and falling back to `progressive.unownedInvariantIds()`. Feed the result into `buildFinalPrdRepairMessage` at :580-585 via the new input field of ADR-007, and append the invariant clause to the empty-tail failure message at :625 after the obligation clause. Retry count stays 3.
**Consequences:** Both lanes see the identical receipt keys `invariantNote`/`unownedInvariantIds`. The optional shim method means an older publisher object still type-checks and degrades to an empty gap.
