# ADR-0005: Aggregate field-level defects within a single predicate instead of throwing on the first bad field

**Status:** Accepted
**Context:** The entry loop already collects one defect per entry, but `parsePredicate` throws at its first failing field, so a predicate with a drifted `kind` and a dropped `pathPrefix` reports only one of them and can cost a second repair round. "Collect every defect" means field level too.
**Decision:** Convert the private `parsePredicate(value, index)` in `goal-constraint-appendix.ts` to `parsePredicate(value: unknown, index: number, defects: ContractDefect[]): GoalConstraintPredicateWireV1 | null`, pushing `{ path, message }` instead of throwing and returning `null` when it pushed anything. Keep every existing message string byte-identical; keep the existing `path` spellings (`constraintPredicates[i]` for entry-level and cross-field rules, `constraintPredicates[i].<field>` where the current code already scopes to a field). Short-circuit and return `null` immediately after the two structural checks — `must be an object` (:157-159) and `must use the exact predicate shape` (:161-165) — since no field check is meaningful afterwards. Otherwise run checks in this order, each independent: `invariantId` (string/length then `INVARIANT_ID` regex), `kind` (string then `absent`/`unchanged`), `pathPrefix`, `pathSuffix`, `text` (string, empty allowed, trimmed, <=200); then the cross-field rules, skipped only when `kind` was itself invalid: absent-needs-pathPrefix-and-text, unchanged-needs-pathSuffix; then the `pathPrefix` repository-relative rule (both kinds); then the bare-extension `pathSuffix` rule (unchanged only, skipped when `pathSuffix` was not a valid string). Keep the caller's `try/catch` around key normalization only.
**Consequences:** A single mangled predicate can now yield several defects. Existing assertions in `test/goal/goal-constraint-appendix.test.ts` that pin `error.defects` for an entry with more than one problem must be updated to the fuller list; messages themselves do not change, and the `error.message === defects.map(d => d.message).join("; ")` invariant is preserved.
