# ADR-0005: Adopt the awake clock across the architect phase budget (run-architect.ts and architect-openai.ts)

**Status:** Accepted
**Context:** scripts/run-architect.ts:328 holds the phase origin as a local `t0` and compares `Date.now() - t0` at :400, :429 and :852, with a bare `setTimeout` abort at :769; the origin is already threaded as data (`startedAtMs` in `compileObligations`'s input, :747-756, passed at :474). architect-openai.ts:116-141 builds `startedAt`/`deadlineAt` inline, races a timeout, then re-checks absolutely; `RunArchitectOpenAIOptions` already has a `testRuntime?` seam (:82-83) but no clock. ADR-0007's dominance test drives this script through a real child process, so its budget arithmetic must not change shape.
**Decision:** scripts/run-architect.ts: resolve `const clock = sharedAwakeClock()` once in `main()`; replace `Date.now()` at :328, :400, :429, :511, :516 with `clock.awakeNow()`; add `awakeClock: AwakeClock` to the `compileObligations` input object next to the existing `startedAtMs` and use `clock.awakeNow()` for `remainingMs` (:758) and the post-settle re-check (:852). Replace the bare `setTimeout` at :769 with `createAwakeDeadline({ budget: "architect-obligations", timeoutMs: remainingMs, onExpired: () => controller.abort(timeoutError), clock })`, closed where `clearTimeout` is called today (:859). `architectPhaseBudgetMs` (:867-869, `args.timeoutMs ?? 1_800_000`) and `architectDeadlineError` (:871) keep their signatures and their message templates byte-for-byte — the stderr text `shared <N>ms phase budget` must not change.

src/planning/adapters/architect-openai.ts: add `awakeClock?: AwakeClock` to `RunArchitectOpenAIOptions` (not to `ArchitectOpenAITestRuntime`); resolve at the top of `runArchitectOpenAI`; `startedAt`/`deadlineAt` (:116-117) become awake values; the phase race timer (:127-134) becomes `createAwakeDeadline({ budget: "architect-phase", ... })`; the post-race re-check (:137) uses `clock.awakeNow() >= deadlineAt`; the per-round timer (:322-329) becomes `createAwakeDeadline({ budget: "architect-round", timeoutMs: perRoundTimeoutMs, ... })`. `retryFitsInPhase(deadlineAt, clock)` and `assertArchitectPhaseDeadline(timeoutMs, deadlineAt, clock)` take the clock as a trailing parameter; `MIN_RETRY_HEADROOM_MS` (:516) keeps its value. `phaseDeadlineAt` threaded through `runArchitectOpenAIWithinBudget(opts, phaseSignal?, phaseDeadlineAt?)` (:144-148) is henceforth an awake timestamp — document that in one line at the parameter.
**Consequences:** `phaseDeadlineAt` changes meaning (awake epoch, not wall epoch) but not type, so every producer of that value must obtain it from the same clock instance; the only producers are in these two files. A multi-hour suspend inside the 30-minute default budget no longer aborts the architect, while the same awake elapsed without suspension still does.
