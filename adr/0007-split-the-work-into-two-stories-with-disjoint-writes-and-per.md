# ADR-0007: Split the work into two stories with disjoint writes and perimeter-only test commands

**Status:** Accepted
**Context:** The goal requires each story to declare an exact non-overlapping `writes` array and to verify only its own perimeter; repo-wide suite commands are rejected by the shell, and package.json:15 `npm test` is repo-wide.
**Decision:** Story A — 'latest candidate wins' — writes exactly: `packages/baro-orchestrator/src/acceptance/turn-review.ts`, `packages/baro-orchestrator/test/acceptance/turn-review.test.ts`, `packages/baro-orchestrator/src/harness/claude/story-agent.ts`. Declared test command (cwd `packages/baro-orchestrator`): `node --import tsx --test "test/acceptance/turn-review.test.ts" "test/acceptance/stale-evidence-recovery.test.ts"`.
Story B — tokenize quote unwrapping — writes exactly: `packages/baro-orchestrator/src/verification/declared-verification.ts`, `packages/baro-orchestrator/test/verification/declared-verification.test.ts`. Declared test command (cwd `packages/baro-orchestrator`): `node --import tsx --test "test/verification/declared-verification.test.ts"`.
Neither story may declare `npm test`, `npm run test`, or any repo-wide/`test/**` glob command. Neither story installs dependencies. Story A owns all edits to src/acceptance and test/acceptance; Story B owns all edits to src/verification and test/verification; neither story may edit src/harness/one-shot/turn-review.ts or src/events/execution.ts.
**Consequences:** The two stories can run fully in parallel — no shared file, no shared symbol. The full suite is proven once by the run-level gate after integration. If a targeted test flakes under load, one isolated rerun of that single file decides.
