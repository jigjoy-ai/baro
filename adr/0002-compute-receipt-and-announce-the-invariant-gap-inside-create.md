# ADR-0002: Compute, receipt and announce the invariant gap inside createPlannerProgressivePublisher

**Status:** Accepted
**Context:** planner-openai-progressive.ts:244-327 is the one admission body for all three adapters (harness and bus-session sit above it), and it already computes and receipts the obligation gap there. The obligation twin announces only on stderr; the goal requires an announced run-stream warn, and the conformance test needs a capturable sink because no event journal exists.
**Decision:** In packages/baro-orchestrator/src/planning/adapters/planner-openai-progressive.ts, immediately after the existing obligation block (:296-314) and using the `goalContract` already derived at :238:
- `const unownedInvariants = unownedInvariantIds(goalContract, session.snapshot().stories)`; `const totalInvariants = goalContract?.invariants.length ?? 0`.
- Receipt (returned object at :315-326) gains, before the `...(hostFeedback ?? {})` spread: `invariantNote` (only when `totalInvariants > 0 && unownedInvariants.length > 0`) and `unownedInvariantIds: [...unownedInvariants]` (only when `unownedInvariants.length > 0`). Exact note text: `` `WARNING: ${unownedInvariants.length} of ${totalInvariants} goal invariant(s) are still unowned after this fragment: ${formatInvariantIdList(unownedInvariants)}. Published stories are immutable — an invariant not claimed at publish time can never be claimed, and planning closes incomplete.` ``
- stderr, gated on `totalInvariants > 0` (mirrors :309-314): `` `[planner-invariants] fragment ${admission.fragmentId} admitted; unowned ${invariantGapSummary(unownedInvariants, totalInvariants)}\n` ``
- Run-stream announcement, gated on `totalInvariants > 0 && unownedInvariants.length > 0`: call the sink `config.onInvariantCoverageGap ?? emitInvariantCoverageGap` with `{ fragmentId: admission.fragmentId, unownedInvariantIds: unownedInvariants, totalInvariants }`.
Add to packages/baro-orchestrator/src/planning/application/plan-events.ts: `export interface InvariantCoverageGap { readonly fragmentId: string; readonly unownedInvariantIds: readonly string[]; readonly totalInvariants: number }`, `export type InvariantCoverageGapSink = (gap: InvariantCoverageGap) => void`, and `export function emitInvariantCoverageGap(gap: InvariantCoverageGap): void` which calls `emitPlanActivity("warn", `[planner-invariants] fragment ${gap.fragmentId}: ${gap.unownedInvariantIds.length}/${gap.totalInvariants} goal invariant(s) unowned: ${formatInvariantIdList(gap.unownedInvariantIds)}`)` — ungated, exactly like emitObligationNote.
Add `readonly onInvariantCoverageGap?: InvariantCoverageGapSink` (optional) to `PlannerOpenAIProgressiveConfig`, and `unownedInvariantIds(): readonly string[]` to the `PlannerProgressivePublisher` surface, implemented next to the existing obligation accessor at :360-365.
Do NOT change the hard gate order: validateGoalContractCoverage at :260 stays where it is, still mode `"partial"`.
**Consequences:** Receipt keys stay overridable by hostFeedback exactly as the obligation keys are. The optional sink keeps default behavior identical in production while letting tests capture without monkey-patching stdout. Adding an optional config field and a new accessor method is source-compatible for existing construction sites.
