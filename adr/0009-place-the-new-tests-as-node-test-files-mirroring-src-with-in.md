# ADR-0009: Place the new tests as node:test files mirroring src, with injected seams instead of real npm/cargo

**Status:** Accepted
**Context:** test/ mirrors src/ with <name>.test.ts and fakes side effects via temp dirs (test/execution/helpers.ts:53-63) and injected binaries (test/harness/claude/cli-participant.test.ts:22-46,111-114). Tests are not typechecked, and `npm test` is the gate (package.json:15).
**Decision:** Add exactly these files, all `describe`/`it` from node:test with node:assert/strict, using `withTempDir` from ../execution/helpers.js and relative `.js` source imports:
- packages/baro-orchestrator/test/integration/dependency-materializer.test.ts — (a) identical lockfile bytes + host node_modules ⇒ `action: "linked"` and `lstatSync(join(run,"node_modules")).isSymbolicLink()` is true and `runInstall` was never called; (b) differing lockfile bytes ⇒ `action: "installed"` and the injected `runInstall` received the workspace dir; (c) host without node_modules ⇒ `action: "installed"`; (d) an injected `runInstall` that rejects produces an Error whose message contains `npmCachePath()` and `npm ci --prefer-offline`; (e) a root + one `packages/*` workspace fixture proves per-workspace verdicts. Always pass `runInstall`; never spawn npm.
- packages/baro-orchestrator/test/verification/cargo-env.test.ts — existing host `target/` wins; absent `target/` yields a path under `join(homedir(), ".baro", "cargo-target")` that is stable across two calls and differs for two different host roots; a preset `CARGO_TARGET_DIR` in the passed env is returned unchanged.
- packages/baro-orchestrator/test/verification/verify-command-cwd.test.ts — `resolveCommandCwd` behavior must be observed through `verifyBuild` (export nothing new for it): a plan whose spec cwd points at a deleted directory outside the run cwd resolves to the run cwd; a missing resolved cwd yields one `failed` outcome whose tail contains the exact expected path, with `retriedAfterFailure` falsy — assert no second attempt via a command that appends to a file. Inject `sleep: async () => {}` in any test that exercises the retry path.

Per-file verification commands are `cd packages/baro-orchestrator && npx tsx --test test/<path>.test.ts`; the run-level gates stay `npm run typecheck` and `npm test` in packages/baro-orchestrator plus `cargo build` and `cargo test` at the repo root.
**Consequences:** No test spawns npm or cargo, so the suite stays offline and fast. Because tests are outside tsconfig include, type drift in fixtures surfaces only at runtime — agents must run the per-file command they declare.
