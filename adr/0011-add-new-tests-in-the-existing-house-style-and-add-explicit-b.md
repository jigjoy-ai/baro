# ADR-0011: Add new tests in the existing house style and add explicit bit-identity regressions for the untouched routes

**Status:** Accepted
**Context:** The test file uses node:test + assert/strict, withTempDir from ../execution/helpers.js, 4-space indent, no semicolons, double quotes, and asserts either assert.equal(spec?.incompleteReason, undefined) on accept or assert.match(spec?.incompleteReason ?? "", /…/) on reject. Acceptance demands exact args and containedPaths assertions for ddev.
**Decision:** Append new `it(...)` cases inside the existing `describe("declared verification policy", ...)` block; do not create a new describe and do not restructure existing cases. Use withTempDir prefixes 'baro-verify-declared-composer-', 'baro-verify-declared-phpunit-', 'baro-verify-declared-ddev-'. Fixtures: composer.json via `writeFileSync(join(dir, "composer.json"), JSON.stringify({ name: "acme/app", scripts: { test: "phpunit", check: "phpunit", custom: "echo" } }))`; phpunit binary via `mkdirSync(join(dir, "vendor", "bin"), { recursive: true })` + `writeFileSync(join(dir, "vendor", "bin", "phpunit"), "")`; ddev via `mkdirSync(join(dir, ".ddev"), { recursive: true })` + `writeFileSync(join(dir, ".ddev", "config.yaml"), "name: app\n")`. Required cases: composer accept (`composer test`, `composer run check` → deepEqual args ["run","test"]/["run","check"], tool "composer", containedPaths undefined); composer rejects (missing composer.json, undeclared script, untrusted `custom`, trailing arg `composer run test --filter x`, unsafe name) each asserted with assert.match on the exact reason substring; phpunit accept bare / --testsuite unit / -c phpunit.xml / bare test path, asserting tool is the absolute binary path and deepEqual on containedPaths; phpunit rejects (binary absent, `../outside.php` escape, `--filter x`); ddev accept wrapping both inner forms with exact deepEqual on args AND containedPaths; ddev rejects (missing .ddev/config.yaml, `ddev ssh`, `ddev exec` with no command, `ddev exec composer run custom` asserting the reason equals the reason returned by translating `composer run custom` directly in the same temp dir). Add one regression case that, in a single temp dir, translates `npm test`, `cargo test`, `node --test safe.js` and `git diff --check` and asserts their full {label, tool, args} against literals — proving the existing routes are unchanged. Never assert on declaredRequirementKey values.
**Consequences:** Coverage maps one-to-one onto the acceptance criteria, and the direct-vs-wrapped reason comparison mechanically proves ddev launders nothing. Absolute-path assertions must tolerate macOS /var symlink normalisation the same way existing contained-path tests do.
