# ADR-0005: Split the work into two sequential stories with disjoint writes

**Status:** Accepted
**Context:** Constraints require every story to declare a non-overlapping `writes` array and verify only its own perimeter. The call-site rewiring cannot compile before the helper exists, so the two stories are dependent, not parallel.
**Decision:** Story 1 — 'Add persistPrdPreserving'. writes: ["packages/baro-orchestrator/src/prd.ts", "packages/baro-orchestrator/src/main.ts", "packages/baro-orchestrator/test/prd-persist-preserving.test.ts"]. Verification: `node --import tsx --test test/prd-persist-preserving.test.ts` plus a typecheck of the package.
Story 2 — 'Route all full-file writers through persistPrdPreserving', dependsOn Story 1. writes: ["packages/baro-orchestrator/src/execution/conductor.ts", "packages/baro-orchestrator/src/execution/runtime-replan-coordinator.ts", "packages/baro-orchestrator/src/execution/collective-board.ts", "packages/baro-orchestrator/src/orchestrate.ts", "packages/baro-orchestrator/test/execution/conductor-persist-preserving.test.ts", "packages/baro-orchestrator/test/execution/goal-fingerprint-preservation.test.ts"]. Verification: the two new test files plus the pre-existing targeted tests for the files it edits — `test/execution/conductor.test.ts`, `test/execution/collective-board.test.ts`, `test/execution/prd-status-writer.test.ts`, `test/execution/resume-selection.test.ts`.
Neither story writes `packages/baro-orchestrator/src/execution/prd-status-writer.ts`, any file under `crates/`, or any existing test file. No package installs; use the already-installed root dependencies.
**Consequences:** The two stories are serialized, so no write overlap is possible. The full-suite check is the run-level gate after integration, once — not per story.
