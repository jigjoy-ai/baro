# ADR-0002: Refactor the dispatcher into a reusable dispatchDeclared() and keep the existing branch order byte-identical

**Status:** Accepted
**Context:** ddev exec must re-run the same policy on the inner command, which requires a re-entrant dispatch. The pre-tokenize steps (declarationError, tokenize) must NOT re-run for the inner command, and trustedScriptAlias plus the existing tool switch must keep their current order so npm/cargo/node/git output stays bit-identical.
**Decision:** Split the current body of translateDeclaredTests's per-requirement callback at line ~57 (the trustedScriptAlias step). translateDeclaredTests keeps: declarationError check (:48-50), tokenize check (:51-52), then calls `dispatchDeclared(cwd, requirement, parsed, managers, false)`. New private function signature: `function dispatchDeclared(cwd: string, requirement: DeclaredTestRequirement, parsed: DeclaredTokens, managers: readonly VerifyJavaScriptPackageManager[], insideDdev: boolean): VerifyCommandSpec`. Its body is the existing code from trustedScriptAlias (:57) through the catch-all (:95-98), unchanged, with three new branches inserted AFTER the existing `git` branch and BEFORE the catch-all, in this order: `tool === "composer"` → translateComposer; `tool === "vendor/bin/phpunit"` → translatePhpunit; `tool === "ddev"` → translateDdev(..., insideDdev). No existing branch, guard, or string is edited except the catch-all message (ADR-008). trustedScriptAlias runs for the inner ddev command too (it is inside dispatchDeclared) — this is intentional and accepted.
**Consequences:** Existing routes execute the identical code path, satisfying the bit-identical regression requirement. The recursion point is a single named function, so no agent invents a second dispatch table. insideDdev is threaded only to reject nesting (ADR-006).
