# ADR-0005: Emit workspace-scoped specs with the workspace cwd and no selector in args, keeping the declared spelling only in the label

**Status:** Accepted
**Context:** VerifyCommandSpec has an optional cwd (verify.ts:75) that verify.ts already uses for workspace commands (verify.ts:443), and rewriteJavaScriptCommandForAuthority matches authorities by exact absolute cwd (verify.ts:844-845). Forwarding '-w' into args would make the command manager-version dependent (yarn 1 vs 2, pnpm) and would double-scope; running the manager in the workspace directory is uniform.
**Decision:** For a resolved workspace selector: (1) run manifest, script-exists and TRUSTED_PACKAGE_SCRIPTS checks against the WORKSPACE package.json at authority.cwd instead of the root one; TRUSTED_PACKAGE_SCRIPTS itself is not modified or extended. (2) Build tool/args with the existing packageCommand(authority, script, trailingArgs) using the resolved workspace authority, so args stay ["run", script, ...trailingArgs] (or ["yarn","run",...] under corepack) — do NOT append "-w"/"--workspace" to args. (3) Set `cwd: authority.cwd` on the returned spec; the no-selector path continues to omit cwd entirely. (4) label = [authority.manager, "run", script, ...declaredSelectorTokens, ...trailingArgs].join(" "), where declaredSelectorTokens is the `declared` array from ADR-002 verbatim — so `npm run typecheck -w @baro/orchestrator` labels as `npm run typecheck -w @baro/orchestrator` and `--workspace=app` keeps the `=` spelling. (5) canonicalDeclaredFocus: "rstest" is decided with exactRstestScript against the SAME manifest used for the checks (workspace manifest when scoped); its other conditions are unchanged. (6) containedPaths from focusedPathRequirement are produced exactly as today, relative to the repository root, not re-based on the workspace.
**Consequences:** A script that exists only in a workspace now verifies. Existing root-scoped labels and specs are byte-identical. The spec's cwd is absolute, so tests must compare against join(dir, "packages", "app") built with the same helpers as the fixture.
