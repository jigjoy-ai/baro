# ADR-0003: Expose supersession through a new optional `onSupersede` lifecycle callback owned by turn-review.ts

**Status:** Accepted
**Context:** turn-review.ts emits no logs or semantic events itself; its only outbound channel is the `StreamingTurnLifecycleOptions` callbacks at lines 32-34, consumed by src/harness/claude/story-agent.ts:541-562. The acceptance criterion requires supersession to be visible in the agent log or state detail, but the goal's non-goals keep edits outside the two target files minimal. Adding a logger import into the pure lifecycle module was rejected (it has no logging dependency today and tests would need to intercept it).
**Decision:** In src/acceptance/turn-review.ts add to `StreamingTurnLifecycleOptions` (32-34) an OPTIONAL callback:
`readonly onSupersede?: (event: { readonly supersededTerminalId: string; readonly terminalId: string; readonly turnsObserved: number }) => void`.
Call it from the supersession branch of ADR-001, wrapped in try/catch whose catch swallows the error (a reporting failure must never fail the story). Also add a public read accessor on `StreamingTurnLifecycle`: `supersededTerminals(): readonly string[]` returning, in arrival order, the ids that were superseded (backed by a private `readonly superseded: string[] = []` pushed to in the same branch).
Wire it in src/harness/claude/story-agent.ts inside `setupMultiTurnLifecycle` (~541-562) by adding one property to the options object literal, emitting the detail string exactly `superseded terminal ${supersededTerminalId} -> ${terminalId}` through the state/detail or log helper that file already uses for this agent (reuse the existing helper; do not import a new logging dependency and do not send it as a user message via `claude.sendUserMessage`). No other file may be modified for visibility.
**Consequences:** Tests assert on `onSupersede` and/or `supersededTerminals()` at the lifecycle level, not through the Claude harness, so the harness wiring stays a one-line addition. The callback is optional, so every existing construction site of `StreamingTurnLifecycle` keeps compiling unchanged.
