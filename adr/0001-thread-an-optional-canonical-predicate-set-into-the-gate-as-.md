# ADR-0001: Thread an optional canonical predicate set into the gate as a third parameter

**Status:** Accepted
**Context:** Canonicalization needs a canonical appendix, and none is reachable from `goal-constraint-appendix.ts` today (it imports only `contract-normalization.js` and `goal-precondition.js`). Deriving canon from the GoalContract is impossible: the contract holds prose constraints and ids, not `kind`/`pathPrefix`/`text` file facts. Making canon mandatory would change behavior everywhere and break the acceptance criterion that existing gate behavior is unaffected. An options-object refactor would churn every existing test, which passes the note recorder positionally.
**Decision:** Extend the existing export in `packages/baro-orchestrator/src/goal/goal-constraint-appendix.ts` to `validateGoalConstraintPredicates(value: unknown, onNote?: NoteSink, canonical?: readonly GoalConstraintPredicateWireV1[]): GoalConstraintPredicateWireV1[]`. Do NOT introduce an options object and do NOT reorder the first two parameters. When `canonical` is `undefined` or an empty array, the function behaves exactly as it does today (canonicalization off). Add the same optional third parameter to `parseGoalConstraintContract(decisionDocument, onNote?, canonical?)`, forwarded verbatim.

Thread it through the outcome gate: add `readonly canonicalConstraintPredicates?: readonly GoalConstraintPredicateWireV1[]` to the existing options interface consumed by `validateArchitectOutcome`/`parseArchitectOutcome` in `packages/baro-orchestrator/src/planning/domain/architect-outcome.ts`, and pass it as the third argument at the constraint-predicate call site (~:352-360). Change nothing about `trustedGoalEnvelope` or the obligation binding.

Production wiring lives in `packages/baro-orchestrator/scripts/run-architect.ts`, next to where `validateOutcome`/`outcomeSchemaSummary` are wired (~:706-711): compute the canon once, before the session starts, from the trusted prior decision document — `hasGoalConstraintFence(prior) ? parseGoalConstraintContract(prior) : undefined` — and pass it into the outcome options. When there is no prior fenced appendix, pass `undefined`. Do NOT capture canon from an earlier attempt inside `architect-bus-session.ts`; that adapter gains no new state.
**Consequences:** Every existing call site and test keeps compiling unchanged. The canonicalization path is only exercised on re-plan/repair of a document that already carries a `baro-constraints-v1` fence, and in tests that supply canon explicitly. `goal-constraint-appendix.ts` still imports nothing from `goal-contract.js`.
