# ADR-0008: Verification commands and scope limits

**Status:** Accepted
**Context:** Stories need fixed checks, and the goal forbids docs/README edits and public API renames.
**Decision:** Rust: `cargo test -p baro-tui git:: branch_authority:: resume::`, then `cargo build -p baro-tui`.

TS: `cd packages/baro-orchestrator && node --import tsx --test test/integration/integration-worktree.test.ts test/integration/worktree.test.ts test/integration/host-checkout-untouched-orchestrate.test.ts`, then `npm test` in that package.

Do not edit README.md, docs/, adr/ or CHANGELOG.md. Do not rename create_fresh_branch, checkout_and_load_prd, verify_execution_branch or IntegrationWorktree methods. Follow CLAUDE.md's style: keep comments lean, 1-3 lines.
**Consequences:** Files that may change: crates/baro-tui/src/{git.rs, branch_authority.rs, resume.rs, main.rs}; packages/baro-orchestrator/src/orchestrate.ts; the three TS test files listed above plus related Rust inline tests.
