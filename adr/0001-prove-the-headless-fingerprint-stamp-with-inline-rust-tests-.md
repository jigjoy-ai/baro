# ADR-0001: Prove the headless fingerprint stamp with inline Rust tests around stamp_goal_fingerprint + write_prd, and do not restructure the headless path

**Status:** Accepted
**Context:** The measured gap assumed the headless path never stamps. Reading main.rs shows both headless persist sites (1810-1821, 1252-1267) already route through confirm_and_execute, which stamps at :3972 before write_prd at :3973; the untested surface is stamp_goal_fingerprint itself and the persisted-then-reloaded round trip that decide_launch consumes. confirm_and_execute is async and needs App + mpsc::Sender, so testing it directly is disproportionate; extracting a new module would churn main.rs for no behavioural gain. The crate has no tests/ dir and no dev-dependencies, so a new integration-test target is off-convention.
**Decision:** Work only in crates/baro-tui/src/main.rs.
1. Audit, and record in the PR description, every prd.json persist site and whether it stamps: :3972-3973 (confirm_and_execute; both headless entries 1252-1267 and 1810-1821 reach it), :2620-2621, :2644-2645, :4130. If any site persists a freshly planned PRD without a preceding stamp_goal_fingerprint call, add the call immediately before the executor::write_prd call at that site; change nothing else. Do NOT change fn signatures of confirm_and_execute or begin_progressive_execution, do NOT change CLI parsing, do NOT touch crates/baro-tui/src/cli/*.
2. Add tests to the existing `mod tests` in main.rs (currently around :4398-4408), importing `use super::stamp_goal_fingerprint;`, `use crate::executor::{self, PrdFile};`, `use crate::cli::launch::{goal_fingerprint, decide_launch};`, `use std::fs;`. Exact tests, named in the repo's sentence style:
   - `a_headless_persist_stamps_the_launch_goal_fingerprint`: build `let mut prd = executor::prd_from_review("atomic", "baro/atomic", "complete snapshot", &[], None, None);` (same constructor used at executor.rs:607-614), call `stamp_goal_fingerprint(&mut prd, Some("ship the launcher"))`, `let dir = tempfile::tempdir().unwrap(); executor::write_prd(&prd, dir.path()).unwrap();`, re-read `dir.path().join("prd.json")` via `serde_json::from_str::<PrdFile>(&fs::read_to_string(..).unwrap()).unwrap()`, assert `reloaded.goal_fingerprint == Some(goal_fingerprint("ship the launcher"))`.
   - `a_stamped_prd_lets_decide_launch_match_the_same_goal`: reuse the reloaded fingerprint and assert `decide_launch(false, false, Some("ship the launcher"), reloaded.goal_fingerprint.as_deref(), true)` yields the same resume decision the existing matrix at launch.rs:186-195 asserts for a matching fingerprint.
   - `an_absent_launch_goal_leaves_the_fingerprint_unset`: `stamp_goal_fingerprint(&mut prd, None)` keeps `goal_fingerprint == None`.
   - `an_already_stamped_fingerprint_is_preserved`: pre-set `prd.goal_fingerprint = Some("fnv1a64:0000000000000000".into())`, stamp with a different goal, assert unchanged (documents get_or_insert_with at :3947-3948).
3. Verification command for this story: `cargo test -p baro-tui goal_fingerprint`. Do not run repo-wide suites.
**Consequences:** Fixes the untested seam without touching async plumbing or CLI surface. If the audit finds every site already stamps, the story is characterization-only and the PR description must say so explicitly rather than inventing a fix. main.rs is written by this story alone; no other story may edit it.
