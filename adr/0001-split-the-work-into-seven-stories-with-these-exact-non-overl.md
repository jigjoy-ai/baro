# ADR-0001: Split the work into seven stories with these exact, non-overlapping writes arrays

**Status:** Accepted
**Context:** The goal demands maximum parallelism with disjoint writes. Rust module declarations (cli/mod.rs) and main.rs are natural collision points, so each new capability is placed in a file whose owner also owns its declaration site, and all main.rs/orchestrator_client.rs wiring is concentrated in one late story.
**Decision:** Exactly seven stories; no path appears in two writes arrays.
S1 rust-cli-flags — writes: ["crates/baro-tui/src/cli/cli.rs"]. Owns all new clap flags + goal-file/positional resolution + help text (ADR-002, ADR-003, ADR-007, ADR-011 help wording).
S2 rust-registry-watch — writes: ["crates/baro-tui/src/cli/run_registry.rs"]. Owns RunRecord log path, log dir helpers, and the `watch`/`logs` command handlers (ADR-004, ADR-005), following the existing print_runs/run_stop convention already hosted in this file.
S3 rust-launch-logic — writes: ["crates/baro-tui/src/cli/mod.rs","crates/baro-tui/src/cli/launch.rs"]. New file holds the pure detach-plan, caffeinate-decision, goal fingerprint and bare-launch-mode functions (ADR-004, ADR-011); mod.rs gains exactly one `pub mod launch;` line.
S4 rust-prd-schema — writes: ["crates/baro-tui/src/executor.rs"]. Adds the new PRD fields to PrdFile/PrdStory so Rust round-trips them (ADR-008, ADR-011).
S5 rust-wiring — writes: ["crates/baro-tui/src/main.rs","crates/baro-tui/src/orchestrator_client.rs"]. Wires detach spawn, BARO_RUN_ID scrub, watch/logs dispatch, --shell-budget env, --resume argv, bare-launch decision, and the --continue progressive fallback (ADR-006, ADR-007, ADR-009, ADR-010). Depends on S1-S4.
S6 ts-prd-status-resume — writes: ["packages/baro-orchestrator/src/prd.ts","packages/baro-orchestrator/src/events/integration.ts","packages/baro-orchestrator/src/integration/git-coordinator.ts","packages/baro-orchestrator/src/integration/local-repository-agent.ts","packages/baro-orchestrator/src/execution/prd-status-writer.ts","packages/baro-orchestrator/src/execution/resume-selection.ts","packages/baro-orchestrator/src/orchestrate.ts","packages/baro-orchestrator/scripts/cli.ts","packages/baro-orchestrator/test/execution/prd-status-writer.test.ts","packages/baro-orchestrator/test/execution/resume-selection.test.ts"] (ADR-008, ADR-009).
S7 ts-workspace-selector — writes: ["packages/baro-orchestrator/src/verification/declared-verification.ts","packages/baro-orchestrator/test/verification/declared-verification.test.ts"] (ADR-012).
**Consequences:** S5 and S6 are the two heavy stories; S1-S4 and S7 run fully in parallel. No story may edit a file outside its array — if S5 discovers a needed change in cli.rs it must be reported, not made. forwarders/story-lifecycle.ts is deliberately NOT touched (ADR-008 wires the writer in orchestrate.ts).
