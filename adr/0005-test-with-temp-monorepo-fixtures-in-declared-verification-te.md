# ADR-0005: Test with temp monorepo fixtures in `declared-verification.test.ts`

**Status:** Accepted
**Context:** The house style is `node:test` with `node:assert/strict`, using `withTempDir` from `test/execution/helpers.ts`. The acceptance criteria require a temp monorepo with a root `workspaces` field and two packages.
**Decision:** 1. Add the tests to the existing `packages/baro-orchestrator/test/verification/declared-verification.test.ts`. Do not create a new file.
2. Fixture helper, local to that file: `writeMonorepo(dir, { aTest?: boolean, bTest?: boolean })`. It writes:
   - root `package.json`: `{"name":"root","private":true,"workspaces":["packages/*"]}`, with no `test` script
   - `packages/a/package.json` and `packages/b/package.json`, each with `name` set, and `scripts: { test: "node -e 0" }` only when the flag is set
3. Build plans with `createVerifyPlan(dir, { declaredTests: [{ storyId: "S1", command, changedFiles? }] })` and select the spec with `origin === "declared"`.
4. Required cases:
   - **(a) Only `a` declares `test`; command `npm test`:** `spec.cwd === join(dir, "packages/a")`, no `incompleteReason`, no `preflightFailure`, and the label ends with `(packages/a)`.
   - **(b) Same fixture with `npm run test`:** same result as (a).
   - **(c) Both declare `test`, `changedFiles: ["packages/b/src/x.ts"]`:** `cwd` is `packages/b`.
   - **(d) Both declare `test`, no `changedFiles`:** `preflightFailure` matches `/multiple workspaces/` and names both `packages/a` and `packages/b`; `incompleteReason === undefined`.
   - **(e) Neither declares `test`:** `preflightFailure` contains `inspected workspaces: packages/a, packages/b`; `incompleteReason === undefined`. Also run `verifyBuild(dir, { plan, emitActivity: () => {} })` and assert the command's outcome is failed, not skipped.
   - **(f) Root declares `test`:** the spec has no `cwd`, as today.
   - **(g) `yarn test` form:** resolves to `packages/a`.
5. Verify with:
   `cd packages/baro-orchestrator && node --import tsx --test test/verification/declared-verification.test.ts test/verification/verify.test.ts`
**Consequences:** No new test helpers are shared outside this file, and no new dependencies are added. Existing assertions that expect `does not declare script` in a monorepo fixture with workspace entries must be updated in the same test files.
