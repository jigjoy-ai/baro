# ADR-0003: Emit IntegrationRefused at all four GitCoordinator refusal sites, alongside the unchanged StoryMergeFailed

**Status:** Accepted
**Context:** Refusal control flow is fail-closed today and must stay byte-for-byte equivalent in behavior; only observability is added. `WorktreeRefusalError.invariant` is already in scope at the mergeBack catch but discarded; the pre-merge checks throw plain `Error`s that the outer catch cannot classify.
**Decision:** In packages/baro-orchestrator/src/integration/git-coordinator.ts only:
1. Add a file-local `class CandidateSealRefusalError extends Error { constructor(message: string, readonly invariant: "seal_missing" | "fingerprint_missing") }` and throw it (instead of plain `Error`) at the missing-seal-marker check (~:554-558, invariant `"seal_missing"`) and the missing/invalid-fingerprint check (~:561-566, invariant `"fingerprint_missing"`). Message text unchanged.
2. Add one private helper `private emitIntegrationRefused(args: { storyId: string; runId: string | null; leaseId: string | null; invariant: IntegrationRefusalCode; detail: string; branch: string | null; retryable: boolean; recoveryRef: string | null }): void` that fills `worktreeRetained = this.opts.worktrees?.activePath(storyId) != null`, `recoveryRef = args.recoveryRef ?? this.opts.worktrees?.recoveryRef(storyId) ?? null`, `recoverable = recoveryRef !== null || worktreeRetained`, and emits `IntegrationRefused.create(...)` through the SAME emit call/authority already used for the adjacent `StoryMergeFailed` emission.
3. Call it immediately BEFORE the existing `StoryMergeFailed` emission at each of the four sites:
   - outer catch (~:182-191): invariant = `error instanceof CandidateSealRefusalError ? error.invariant : (error as {invariant?: IntegrationRefusalInvariant}).invariant ?? "unknown"`; `branch: null`; `retryable: false`; `recoveryRef: null` (helper resolves).
   - mergeBack catch (~:387-427): invariant = `(e as {invariant?: IntegrationRefusalInvariant}).invariant ?? "unknown"`; `branch` = the same logical branch already passed to StoryMergeFailed (~:390); `retryable` = the same value already computed there; `recoveryRef` = the ref returned by `prepareConflictRetry` when it succeeded, else null.
   - missing-worktree branch (~:465-474): invariant `"worktree_missing"`, `branch: null`, `retryable: false`.
   - the pre-merge throws reach the outer catch and are covered by (1); do not emit twice.
4. Do NOT reorder, swallow, or add try/catch around existing control flow; do NOT change StoryMergeFailed field values; do NOT touch `WorkspaceCleanupFailed` or LocalRepositoryAgent.
**Consequences:** Every refusal now produces exactly one `integration_refused` plus the existing `StoryMergeFailed`; Board behavior (re-offer vs unmergeable) is unchanged because it keys on StoryMergeFailed. `invariant: "unknown"` is the honest value when an unexpected error escapes — do not invent a code. Emission must never throw: the helper is best-effort and must not sit inside a path that could turn a refusal into a crash.
