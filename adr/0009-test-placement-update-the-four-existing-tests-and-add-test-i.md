# ADR-0009: Test placement: update the four existing tests and add test/integration/integration-worktree.test.ts

**Status:** Accepted
**Context:** node:test plus tsx with real temp git repos. The fixture lives in test/integration/worktree-fixture.ts.
**Decision:** Update these tests for the new option names:
- test/integration/worktree.test.ts: pass `{ integrationRoot }` where the tests merge, and keep the positional repoRoot.
- test/integration/git-coordinator.test.ts and git-coordinator-integration-refused.test.ts: `repoRoot`, `integrationRoot`, `integrationWorktree`. host_checkout_dirty is still exercised by making integrationRoot dirty, or with integrationRoot === repoRoot.
- test/integration/worktree-suspension-lineage.test.ts: its base comes from integrationRoot.
- test/integration/finalizer.test.ts: `cwd` becomes `integrationRoot`.

New file packages/baro-orchestrator/test/integration/integration-worktree.test.ts builds a real temp repo (git init on `main`, one commit), uses uniqueRunId, and calls removeWorktreeRun in finally. It covers four cases:
(a) IntegrationWorktree.prepare plus WorktreeManager with integrationRoot: create a story, commit, mergeBack. Assert that repoRoot's `branch --show-current` and `rev-parse HEAD` are unchanged and that the goal branch contains the merge.
(b) An uncommitted edit in repoRoot to the same file the story changes: mergeBack succeeds, and the host edit is still present.
(c) syncHostCheckout, three ways:
  - clean on main returns fast_forwarded, and host HEAD equals goal HEAD.
  - dirty returns untouched/host_checkout_dirty, and HEAD and the edit are unchanged.
  - host switched to another branch returns untouched/not_on_base_branch.
  None of them throws.
(d) After remove(), on the success flow and after a simulated failure (mergeBack throws merge_conflict, then remove()), integrationWorktreePath(runId) does not exist and is absent from `git worktree list --porcelain`.
Also add a reuse case: calling prepare() twice, or with a new instance for the same runId, returns reused=true on the second call.
**Consequences:** Acceptance requires `npm run typecheck` and `npm test` to pass in packages/baro-orchestrator. Do not change CLI flags, crates/ or any other package.
